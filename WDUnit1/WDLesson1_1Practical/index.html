Web Technologies

HTML

A HTML is a standard code that is used to structure and display information on the internet or the web page. HTML stands for Hypertext Markup Language where you can create web pages that allows you to add images, text, and color to a web page that you find on the internet. HTML is the start of a webpage and allows other people to see the web page and the information on it.

  1. Headings
  2. Paragraph
  3. List
  4. Title
  5. Body

CSS

CSS stands for Cascading Style Sheets. It is used to make websites look better by changing colors, fonts, sizes, and layouts. HTML is the structure of a website and CSS as the design.
  • Display
  • Text
  • Backgrounds
  • Margins
  • Fonts

JavaScript

JavaScript is a programming language used to make websites interactive. It can make buttons work, create animations, and update information on a page. HTML is the structure, CSS as the design, and JavaScript as the action.
  1. Output
  2. Numbers
  3. Timers
  4. Dates
  5. Debugging
